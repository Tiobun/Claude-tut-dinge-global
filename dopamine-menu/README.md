# Dopamine Menu

An ADHD-friendly "menu" of feel-good activities to reach for instead of doomscrolling.
Mid-Century Modern × 1970s Space Age: walnut, warm lamp glow, chrome trim, grey-turquoise corduroy.

- **I can't decide** – shuffles and lands on one random activity.
- Tap any menu item to see it on its own, with nothing else on screen.
- Edit activities in `src/menu.js`.

```bash
npm install
npm run dev      # local dev server
npm run build    # static build in dist/
```

Built with React, Tailwind CSS and Lucide icons.
